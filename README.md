# ai-nz-hackathon-2026

Helpful collection of getting started notebooks.

1. First Login - no projects found. Don't click Create Project (that's an OpenShift project).

![images/first-login.png](images/first-login.png)

2. Login to RHOAI first. Hamburger menu top right.

![images/navigate-rhoai.png](images/navigate-rhoai.png)

3. Create a Data Science Project instead.

![images/create-datascience-project.png](images/create-datascience-project.png)

4. Name your project.

![images/name-your-project.png](images/name-your-project.png)

5. Create a workbench.

![images/create-workbench.png](images/create-workbench.png)

6. Workbench details - `Name`, `Image (Jupyter | Minimal CPU | Python 3.12)` - Create workbench.

![images/workbench-details.png](images/workbench-details.png)

7. Open workbench.

![images/open-workbench.png](images/open-workbench.png)

8. Clone this git repo https://github.com/eformat/ai-nz-hackathon-2026 and use the Notebooks.

![images/clone-repo.png](images/clone-repo.png)
